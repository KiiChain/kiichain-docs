# 🌐 Guide: Contribute to KiiChain Using Ubuntu on Windows (WSL)

This guide is for developers using **Windows Subsystem for Linux (WSL)** to contribute to [KiiChain](https://github.com/KiiChain) documentation, SDKs, and smart contracts.

---

## 🛠️ Step 1: Install Git and Setup Identity

```bash
sudo apt update
sudo apt install git -y
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
Make sure to use the same email as your GitHub account.
