# Security Policy

## Supported Versions
We release patches for security vulnerabilities as needed. Please make sure you are always using the latest version of this repository.

## Reporting a Vulnerability
If you discover a security vulnerability, please report it responsibly by contacting the KiiChain team.

- **Email:** security@kiichain.io  
- **Discord:** [KiiChain Community](https://discord.gg/kiichain)  
- **GitHub Issues:** Please do not post sensitive security issues publicly. Use email instead.

We will investigate all reports and do our best to address valid issues promptly.
