# Documentação do KiiChain (Português-Brasil)

Bem-vindo à documentação do KiiChain, uma blockchain projetada para mercados emergentes como o Brasil. Esta é uma versão inicial em português e será expandida pela comunidade.

## Instruções para Expandir
- Traduza os documentos principais de [README.md](https://github.com/KiiChain/kiichain-docs/blob/main/README.md) para o português.
- Adicione seções como "Instalação" e "Como Contribuir" conforme necessário.
- Envie um pull request com suas traduções para colaboração.

Para mais detalhes, consulte a versão em inglês em [README principal](https://github.com/KiiChain/kiichain-docs/blob/main/README.md).
