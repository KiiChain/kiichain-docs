# KiiChain Project Overview

Welcome to the official documentation & resource repository for the **KiiChain project** — a decentralized Layer 1 blockchain built on Cosmos SDK, designed to support scalable and secure decentralized applications.

> This repo contains public project documents, smart contract samples, roadmap, and technical explanations for both developers and contributors.

---

## 🌐 About KiiChain

KiiChain is a high-performance blockchain protocol offering:
- Fast block finality
- Low gas fees
- Cross-chain capabilities via IBC
- Smart contract support through CosmWasm and EVM compatibility (Kii EVM)
