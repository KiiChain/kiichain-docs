# Endpoints - EVM

Kiichain follows the standard JSON-RPC calls from Ethereum.

You can find more information about all the available endpoints at:

* [JSON-RPC API Methods](https://ethereum.org/developers/docs/apis/json-rpc)

## Mainnet

* **EVM Chain ID:** `1783`
* **JSON-RPC:** [https://json-rpc.kiivalidator.com](https://json-rpc.kiivalidator.com)
* **WebSocket:** wss://ws.kiivalidator.com/websocket

See also: [Kiichain Mainnet](kiichain-mainnet.md)

## Testnet Oro

* **EVM Chain ID:** `1336`
* **JSON-RPC (Sentry #1):** [https://json-rpc.uno.sentry.testnet.v3.kiivalidator.com/](https://json-rpc.uno.sentry.testnet.v3.kiivalidator.com/)
* **JSON-RPC (Sentry #2):** [https://json-rpc.dos.sentry.testnet.v3.kiivalidator.com/](https://json-rpc.dos.sentry.testnet.v3.kiivalidator.com/)

See also: [Testnet Oro](testnet-oro.md)
