# What is KiiChain?

### What is KiiChain?

KiiChain is a Layer 1 blockchain built with the Cosmos SDK. It is an AppChain designed as an abstraction layer for stablecoin and RWA utility and liquidity. It combines EVM compatibility with multi-chain connectivity to create a network that is highly interoperable, scalable, and easy to use. Its core purpose is to onboard the next generation of developers in emerging markets who are building real-world use cases for mass adoption.

### KiiChain Powers KIIEX

KIIEX is a cross-border payment and trading platform that brings institutional liquidity and immediate settlement to the most popular FX and RWA pairs using non-dollar stablecoins.  

### Cosmos SDK

The Cosmos SDK is an open-source framework for building multi-asset public Proof-of-Stake (PoS) blockchains, such as the Cosmos Hub. Its goal is to allow developers to easily create custom blockchains from scratch that can natively interoperate with other blockchains. We envision the Cosmos SDK as an npm-like framework for building secure blockchain applications on top of CometBFT. SDK-based blockchains are composed of modules, most of which are open source and readily available for developers. The Cosmos SDK is a capability-based system that enables developers to better reason about the security of interactions between modules. Learn more about Cosmos [here](https://docs.cosmos.network/).

### CometBFT & Tendermint Core

CometBFT (Byzantine Fault Tolerant) is the upgraded version of Tendermint Core, the Interchain’s consensus mechanism that powers Cosmos SDK blockchains. CometBFT has a modular architecture that separates the consensus engine from the application layer, allowing developers to build custom blockchain applications with ease. It provides fast transaction finality and high throughput, making it ideal for applications that require quick and reliable performance. Learn more about CometBFT [here](https://cometbft.com/).

### Proof-of-Stake

KiiChain is a Proof-of-Stake blockchain. PoS selects validators based on the number of tokens they hold and are willing to "stake" as collateral for securing and servicing the network. Delegators, or individual stakers, can delegate their tokens to any validator that meets the requirements.

### Kii RWA Protocol

The Kii RWA Protocol standardizes Real-World Asset (RWA) tokenization through the T-REX (Token for Regulated EXchanges) protocol, using CosmWasm smart contracts on KiiChain that are simultaneously mirrored to ERC tokens. The T-REX protocol is designed for compliant issuance and management of security tokens on blockchain networks. Beyond token standards, the protocol defines on-chain KYC, KYB, and asset verification. The Kii RWA Protocol on KiiChain is creating an interoperable, unified liquidity layer for RWA tokens.

### Kii PayFi Module

The Kii PayFi Module is a gas-optimized payment system for merchant transactions, featuring specialized fee handling and a Paymaster system to provide gas funds for DeFi actions via protocols. The module is developed for both web3 and web2 companies to incentivize the migration of their revenue and payment models to on-chain functions. It also includes a DeFi protocol that sets standards for TVL-based loans, collateral management, interest models, and liquidity systems. Advanced features include revenue lending, invoice financing, payment scheduling, and TVL-based credit card financing through community PayFi pools. This module is still in development and will be deployed in the coming weeks.

### EVM Module

The EVM Module enables mirrored EVM compatibility, allowing smart contracts written in Solidity to be deployed on the network. This means it can run all existing Ethereum dApps and smart contracts without modification. It achieves this with a high-performance Ethereum Virtual Machine optimized for speed and reliability. Thanks to its modular, plugin-based design, it allows any host blockchain to execute Ethereum transactions and smart contracts.

### IBC

Inter-Blockchain Communication (IBC) is a protocol that enables cross-chain communication and data transfers. It connects different blockchain networks to promote high levels of interoperability, scalability, and communication. IBC can be implemented on any blockchain network that conforms to its protocol guidelines. Currently, more than 100 networks are integrated into IBC. Learn more about IBC [here](https://www.ibcprotocol.dev/).
