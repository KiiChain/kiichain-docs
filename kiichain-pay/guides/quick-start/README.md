# Quick Start

Each guide takes one flow from start to finish with copy-pasteable `curl`. For the concepts behind them — the shared quote → create → act → track loop, the comparison table, and how to discover the IDs each call needs — start with the [Guides overview](../README.md).

- [Creating an on-ramp](creating-an-on-ramp.md) — move **fiat → crypto**. Pay off-platform; no on-chain signing.
- [Creating an off-ramp](creating-an-off-ramp.md) — move **crypto → fiat** into a bank account.
- [Creating an FX swap](creating-an-fx-swap.md) — swap **crypto → crypto** as a custodial, tracked activity.
- [Creating a DEX swap](creating-a-dex-swap.md) — swap **crypto → crypto** on-chain, permissionless — no account, KYC, or activity.
